# Version history

The newest version is at the top.

## 1.0.0 — 24 October 2026

First release.

- Each Levoit air purifier on the VeSync account can be an Indigo switch device, with PM2.5, air quality, fan speed, mode, filter life, child lock, display and whether it is connected as states.
- Actions for fan speed, mode, the automatic-mode setting, child lock, display, a switch-off timer and resetting the filter, each checked before it is sent. The device shows a command at once and holds it while VeSync's status catches up, which on a Core 400S takes one to four minutes.
- Switches the purifier back on after its power has been off (a Core 400S comes back switched off), seen from the plug it runs from or from VeSync.
- A plug that measures power can be named in the device's settings, for the power-cut check and for the Dashboards Air page's power and cost.
- Test Connection, List Account Devices, Refresh All and Show Plugin Info in the Plugins menu.
