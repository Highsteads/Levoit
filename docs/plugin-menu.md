# The plugin menu

**Plugins → Levoit Purifier**

| Item | What it does |
|---|---|
| **Refresh All** | Reads every purifier now instead of waiting for the next check. |
| **List Account Devices** | Writes a line to the Event Log for each air purifier on the VeSync account, saying how it is and whether it is in Indigo yet. |
| **Test Connection** | Writes the plugin's details to the Event Log, signs in, and says whether that worked and what is on the account. The details are what to paste into a forum post if you need help. |
| **Show Plugin Info** | Writes the plugin's version, Indigo's version and the Mac's details to the Event Log. |

Your email address only ever appears in the log shortened, as `c***@example.com`, and the password never does.
